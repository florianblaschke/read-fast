# read-fast

The faster way to read all the lovely .md files generated by agents.

Install
```sh
cargo install --path .
```

Use

```sh
rf <path-to-file>
```


Playback starts immediately at 60 words/minute and stops on the last word.
Press **R** to replay from the beginning at the current speed, or **Q** to quit.
Markdown syntax is retained; words are separated by whitespace.
Each word's middle character is red and anchored at the horizontal center.
Even-length words use the right-hand middle character. Unicode graphemes
(such as accented letters) stay together. Long words are clipped at the edges
without moving the highlighted character.

- **L**: faster (reduce the word interval by 10 ms, minimum 10 ms)
- **H**: slower (increase the word interval by 10 ms, maximum 2000 ms)
- **J**: pause/resume
- **R**: replay from the beginning (also works during playback or while paused)
- **Q** or **Ctrl-C**: quit
